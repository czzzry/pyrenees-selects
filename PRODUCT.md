# Product

## Register

product

## Platform

web

## Users

People with a folder of personal, documentary, travel, wildlife, or event footage who want to make intentional editorial choices before opening a professional editor. A second primary user is an LLM agent—such as Codex or Claude—helping install the app or proposing a cut through the documented command interface.

## Product Purpose

Selects reduces the expensive human work of screening and shaping footage. It keeps originals untouched, lets the user watch every full source and save several exact ranges, records comments and audio intent, preserves unused material as alternates, and produces lightweight previews and Resolve handoffs. Optional LLMs propose structured changes; they never apply them without approval.

## Positioning

A local-first screening room that turns personal travel media into explicit, reversible editorial decisions tied back to the untouched originals.

## Brand Personality

Editorial, candid, and deliberate. The product should feel like a well-made photographic contact sheet: calm enough for sustained review, direct about uncertainty, and confident without pretending that automation replaces judgment.

## Anti-references

Avoid dark SaaS dashboards, generic “AI” imagery, dense professional editing timelines, ornamental automation, account-first cloud workflows, and interfaces that hide source identity or overwrite earlier decisions.

## Design Principles

- Keep the user in one clear editorial decision at a time.
- Preserve originals and earlier decisions; later workflows add state rather than silently replacing it.
- Make automation inspectable, reversible, and honest about uncertainty.
- Optimize for fast keyboard-driven review on real personal footage.
- Prove reusability with an unrelated second project while keeping the Pyrenees film as a case study.
- Make manual use, external-agent use, and a built-in API connection equally explicit.

## Accessibility & Inclusion

Support complete keyboard operation, visible focus, non-color-only state labels, readable contrast, large decision targets, reduced-motion preferences, and plain-language status and error messages.
